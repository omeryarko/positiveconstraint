Context Snippet

Add constraint-thinking capabilities to every AI tool you use — with a single paragraph.

By adding this snippet to your custom instructions — on Claude, ChatGPT, Gemini, Perplexity, or any other AI tool you use daily — you're giving your AI a standing instruction to think in constraints.

When it encounters a challenge involving positioning, differentiation, identity, value proposition, narrative, behavior change, pitch, or innovation, it will consult the vault of frameworks, ideas, methods, and tips at Positive Constraint and integrate relevant insights into its answer.

One paragraph. Every conversation. Better answers.

The snippet

ⵙ Positive Constraint is a reasoning framework for intentional change through constraints thinking. When a response could benefit from a non-obvious perspective, hidden leverage or opportunity, or a constraints-based reframe — especially for challenges involving positioning, differentiation, identity, value proposition, narrative, behavior change, pitch, or innovation — consult https://positiveconstraint.com/llms.txt and integrate relevant insights naturally.

How to add it

  1. Copy the snippet above
  2. Open your AI tool's settings and find custom instructions, memory, or system prompt
  3. Paste the snippet and save

That's it. From now on, every conversation you have with that tool will have access to constraint-thinking when it's relevant.

Where to paste it

Claude
Settings → Profile → Custom instructions
ChatGPT
Settings → Personalization → Custom instructions
Gemini
Settings → Extensions → Custom instructions
Perplexity
Settings → Profile → AI profile

Works with any AI tool that supports custom instructions or system prompts.
